Installation

Compatibility

The current package metadata lists minimum requirements of ExpressionEngine 3 and PHP 5.6. The separate EE1 and EE2 branches are historical versions and are no longer under development.

Install the add-on

  1. Download and unzip Low Yearly Archives.
  2. Copy the low_yearly_archives add-on folder into your ExpressionEngine installation’s system/user/addons/ directory.
  3. In the Control Panel, open the Add-on Manager and install Low Yearly Archives.

Continue with the Tag Reference and the archive list example.
