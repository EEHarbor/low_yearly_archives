Archive list example

This example groups months under their year. Months with matching entries link to an archive template; months without matching entries display their abbreviated name without a link. Change blog to your channel name and blog/archive to your archive template.

The example uses status="open". The older status="not closed" example also includes other non-closed statuses, which may be unsuitable for a public archive.

{exp:low_yearly_archives channel="blog" start_month="1" status="open" sort="desc"}
    {if year_count == 1}<ul>{/if}
    <li>
        {year}
        <ul>
            {months}
                <li>
                    {if num_entries != 0}
                        <a href="{path='blog/archive'}/{year}/{month_num}/"
                           title="{num_entries} entries in {month} {year}">{month_short}</a>
                    {if:else}
                        {month_short}
                    {/if}
                </li>
            {/months}
        </ul>
    </li>
    {if year_count == total_years}</ul>{/if}
{/exp:low_yearly_archives}

start_month="1" displays months from January in the starting year. sort="desc" lists the newest year first; the default month order is ascending.

See the Tag Reference for the existing parameters and year/month variables.
