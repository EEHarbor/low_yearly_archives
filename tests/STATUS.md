## Confirmed source defects

1. Archived `Base/Pi.php:30`: static `info()` references `$this` and throws `Error` before returning usable metadata. All runtimes fail the correct-behavior metadata regression.
2. Archived `Base/Ext.php:187`: `register_extension()` overwrites its provided hook, priority and enabled arguments with defaults. The regression expects the explicitly requested hook/priority/enabled values.
3. Archived `Conduit/StaticCache.php:18`: `empty()` converts stored zero, empty array, null and empty string into false. Separate correct-value regressions require these payloads to round-trip. `StaticCache.php:51` also reports false after successfully deleting an existing key; a success regression remains red.
4. Loose `pi.low_yearly_archives.php:370`: `_explode_param(null)` passes null to `substr`, producing a deprecation on PHP 8.1–8.5. PHP 7.4/8.0 return the legacy empty parameter result. The error handler fails the diagnostic, including under `@`.

5. Archived `Conduit/GlobalFieldSettings.php:21`: `getSetting()` reads a missing key under `@`, emitting an undefined-key diagnostic.
6. Archived `Bridge/EE3.php:412`, `EE4.php:412` and `EE5.php:412` (also inherited by EE6): short frontend URIs access missing segment 3 under `@`.
7. Archived `Base/Upd.php:64`: a normal upgrade includes the absent optional extension under `@`, emitting a missing-file diagnostic.
8. Archived `Conduit/PersistentCache.php:196/215`: uncreatable generic/module directories emit `@mkdir()` diagnostics. Each get/set/delete/clear operation is tested independently so one failing operation cannot hide another.
9. Native PHAR stub line 177 emits `@mkdir(): File exists` during ordinary self-extraction. The native regression remains red under the strict diagnostic policy.
